## 파일 위치

홈페이지 파일은 website 폴더에 있습니다.
- index.html: 홈페이지
- style.css: 디자인
- app.js: 프로젝트와 버튼 동작
- assets/resume.pdf: 이력서

## 확인 방법

외부 이미지, 글꼴, 영상 링크를 불러오려면 인터넷 연결이 필요합니다.
